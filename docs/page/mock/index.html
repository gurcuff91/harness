Start / Quick start

Quick start

Agent = LLM + Harness. If you're not the model, you're the harness.

01Install

Harness is a single binary with no runtime dependencies. Install it with Go, or download a release.

# from source
$ go install github.com/gurcuff91/harness/cmd/harness@latest
$ harness --version
v0.127.0

02Connect a provider

On first run, connect one provider. Subscriptions use a browser flow; API keys are stored locally.

$ harness connect claude-oauth    # Claude subscription
$ harness connect anthropic       # API key
Tip  Ollama running locally is detected automatically — no setup needed.
